# Security policy

Report suspected vulnerabilities through GitHub private vulnerability reporting when the remote repository is activated. If that feature is unavailable, use the organization's approved private security channel. Never disclose a vulnerability, credential, customer record, merchant secret, or provider payload in a public issue.

The Security Engineering owner must acknowledge a report, classify severity, coordinate containment and remediation, and retain evidence. The repository administrator must configure the private reporting channel before Stage 1 exit.
